# Unit Converter

A clean, modern, and responsive Unit Converter built using HTML, CSS, and JavaScript. Convert length, weight, and temperature units with a simple and user-friendly interface.

## ✨ Features

- **Length Conversion** — Meter, Kilometer, Centimeter, Millimeter, Mile, Foot, and Inch.
- **Weight Conversion** — Kilogram, Gram, Milligram, Pound, and Ounce.
- **Temperature Conversion** — Celsius, Fahrenheit, and Kelvin.
- **Real-Time Conversion** — Get results as you enter a value or change units.
- **Swap Units** — Quickly switch between the source and target units.
- **Reset Functionality** — Reset the converter to its default state.
- **Responsive Design** — Clean interface designed for different screen sizes.
- **Input Validation** — Handles empty and invalid numeric input.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the repository:

   ```bash
   git clone https://github.com/aashuyadavv/Unit-Converter.git
   ```

2. Open the project folder:

   ```bash
   cd Unit-Converter
   ```

3. Open `index.html` in your browser.

No additional dependencies or installations are required.
